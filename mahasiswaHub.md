Buat sebuah website full modern, profesional, interaktif, responsif, dan realistis dengan tema “MahasiswaHub” yaitu platform digital gabungan jasa mahasiswa freelance dan pencari magang kerja. Website harus terlihat seperti startup premium Indonesia, setara platform profesional modern. Gunakan HTML, CSS, dan JavaScript murni. Kode harus rapi, terstruktur, mudah diedit, dan bisa langsung dijalankan di VS Code menggunakan Live Server.
